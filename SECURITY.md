# Security reports

Do not include credentials, private server configuration, world saves, browser cookies, or exploit payloads in public issues. Report ordinary bugs using redacted reproduction steps. Until a private reporting channel is configured, keep sensitive details out of the public repository.

This beta is not a sandbox for mod code. Downloaded mods run as the account running the game server. Installation requires deliberate user review; the catalog's server-only classification is not a malware verdict.
